# Provenance and scope

Recovered from the author's existing File Organizer Python/C project and VS Code local history. The selected Python source compiles to the same code object as the application in the original Projects repository (main abf1bcdc7b092df234fe29493c310288503e3b20). Recovered native source produced matching normalized disassembly, not a byte-identical library.

This revision preserves the original interface and category mappings. Changes are limited to no-replace native moves, shared manual/drop/automatic undo, truthful undo outcomes, checked path handling, serialized native calls, main-thread Tk updates, session-only logs and portable source/build paths. No duplicate manager or features from other local variants were imported. The automatic native rule set remains different from the manual Python rules.

Generated bundles, logs, editor-history backups and old packaged runtime trees are not part of this clean history. Tests and documentation were added during portfolio preparation. The original repository and recovery backup remain separate.
